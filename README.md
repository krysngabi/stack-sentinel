<h3 align="center">Stack Sentinel</h3>

  <p align="center">
    Lightweight container and service monitoring system that tracks runtime health,
    detects failures, and sends real-time alerts when containers go down or become unhealthy.
    Designed for self-hosted infrastructures, Docker stacks, and scalable DevOps environments.
  </p>

</div>

---

## Why 🤔

* Monitor Docker containers and critical services in real time
* Detect unhealthy containers automatically
* Receive instant alerts when services go offline
* Lightweight and easy to deploy
* Perfect for homelabs, VPS, and self-hosted infrastructures
* Built for scalability and DevOps environments

---

## Features 🚀

* Container health monitoring
* Service uptime tracking
* Real-time notifications and alerts
* Docker integration
* Multi-container support
* Health check automation
* Lightweight architecture
* Extensible monitoring system

---

## Built With 🛠️

* Java Spring Boot
* Docker
* REST APIs
* MySQL / PostgreSQL
* JWT Authentication
* Scheduling & Health Checks
